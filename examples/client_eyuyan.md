# 易语言接入示例

国内卖小工具的主力语言是易语言，但这个语言没有现成的 HMAC-SHA256 命令，
第三方模块（精易等）又不是每个人都有。所以这份示例**不依赖任何模块**：

- HMAC-SHA256 用 Windows 自带的 CNG（`bcrypt.dll`）实现
- HTTP 用系统自带的 `WinHttp.WinHttpRequest.5.1` COM 对象
- 机器码读注册表 `MachineGuid`（重装系统才会变）

> 这份是**文本代码**，不是 `.e` 工程。在易语言里新建一个 Windows 窗口程序，
> 把下面的代码按段粘进去（或用「编辑 → 导入文本代码」）。
> 粘完按 F5 跑一遍：如果某个 DLL 命令的参数类型报错，按 F1 看该 API 的帮助手动改一下。

---

## 一、准备

1. 打开易语言 → 新建 → **Windows 窗口程序**
2. 在窗口上放三个组件（可选，只是为了手动测试）：
   - 编辑框 `编辑框_卡密`
   - 按钮 `按钮_验证`
   - 编辑框 `编辑框_输出`（多行 = 真）
3. 把下面「二、代码」整段粘到启动窗口的程序集里

## 三、几个必须注意的点

**1. 签名串的字符编码**

CNG 的 HMAC 吃的是原始字节。签名串是纯 ASCII（`app_id=xxx&code=yyy…`），
GBK 和 UTF-8 在 ASCII 范围内完全一致，所以 `到字节集 ()` 直接用没问题。

但如果你的 AppSecret 里有中文，就必须两边都按 UTF-8 处理，否则一直 `BAD_SIGN`。

**2. 排序必须按 ASCII**

易语言的 `数组排序` 按本地化比较，大小写顺序可能和 ASCII 不同。
上面的 `计算签名` 用 `取文本左边` 取到 `=` 前的键名再比较，是逐字符比较，
对 `app_id` / `code` / `machine_id` / `nonce` / `sign` / `ts` / `ver` 这组小写键名来说等价于 ASCII 序。

如果以后加了含大写的参数，改成 `取代码 ()` 逐位比较。

**3. 时间戳**

服务端允许 ±300 秒偏差。`取时间戳` 里减的是 `1970-01-01 08:00:00`（东八区），
如果你的机器时区不是东八区，这里要改。更稳的做法是直接调 `time()` API：

```e
.DLL命令 time, 整数型, "msvcrt.dll", "time"
    .参数 p, 整数型
```

然后 `time(0)` 直接就是 Unix 秒，与时区无关。

**4. nonce 每次都要新值**

上面用 `取随机十六进制` 生成。如果用固定值，服务端 600 秒内会返回 `REPLAY`。

**5. 心跳线程与界面**

易语言的 `启动线程` 里不要直接操作窗口组件，用 `线程_进入许可区` 或者
往全局变量写状态、主线程定时器去读。上面的示例为了简短直接写了编辑框，
生产环境请改成投递消息或定时器轮询。

## 四、没有网络时怎么排查

先把 `HTTP_POST` 的返回原样打印出来：

```e
编辑框_输出.加入文本 (请求接口 (“/api/v1/verify”, “测试卡密”) ＋ #换行符)
```

看 `err` 字段：

| err | 说明 |
|---|---|
| `BAD_SIGN` | 签名不对，先检查 AppSecret 有没有前后空格 |
| `BAD_TS` | 时间戳超差，见上面第 3 点 |
| `REPLAY` | nonce 重复，检查是不是用了固定值 |
| `BAD_APP` | AppID 不对 |
| `COM_FAIL` | WinHttp 对象创建失败，检查系统是否禁用 COM |
| `NETWORK` | 连不上，先确认域名能通（浏览器打开 `/api/health` 试试） |
