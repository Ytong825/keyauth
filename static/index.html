接入前准备

          

            

              
接口地址

              
AppID
先到「应用」页创建

              
AppSecret
同上，用于签名

              
签名算法

                取除 sign 外的全部参数（空值也保留），按参数名 ASCII 升序拼成
                k1=v1&k2=v2，用 AppSecret 做 HMAC-SHA256，输出小写十六进制。
              

              
机器码
CPU + 主板 + 硬盘序列号拼接后取 SHA256 前 32 位。不要用 MAC 地址。

            

          

        


        

          
接口一览

          

            
接口方法用途调用时机

            
              
/api/v1/verifyPOST校验卡密并绑定机器码，首次调用即激活软件启动 / 用户输入卡密

              
/api/v1/heartbeatPOST上报在线、检测是否被封禁或过期运行中每 3~5 分钟

              
/api/v1/queryPOST只查询状态，不绑定、不扣额度展示剩余时长 / 次数

              
/api/v1/unbindPOST用户自助换绑设备（受次数限制）用户点「更换设备」

              
/api/v1/noticesPOST拉取公告列表软件内公告栏
