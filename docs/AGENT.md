## 它是怎么划权限的

代理商不是「小号管理员」，权限是按**配额**给的：

```
代理商 ──┬── 能制哪些应用（app_id）──┐
         └── 每种卡多少张（quota）────┴──▶ 制卡时二选一都必须满足
```

一条配额 = `应用 × 卡类型 × 时长 × 设备数 × 换绑次数 × 数量`。
例如「狠剧ai · 天数卡 30 天 · 1 设备 · 换绑 1 次 · 20 张」。

代理商制卡时**不能自己填规格**，只能从你给的配额里挑一条、填数量。
所以他没法把「30 天卡」改成「永久卡」，也没法把「1 设备」改成「10 设备」。

## 开一个代理商

**管理后台 → 代理商 → 新建代理商**

填三项：登录账号、显示名称、初始密码（至少 6 位）。建完把账号密码给他。

他自己打开 `https://你的域名/agent` 登录，不需要你的管理令牌。

## 分配配额

点该代理商行的「配额」，弹窗里一行一条规格：

| 列 | 说明 |
|---|---|
| 应用 | 下拉选你已有的应用 |
| 类型 | 天数卡 / 小时卡 |
| 时长 | 天数卡填天数，小时卡填小时数，`0` = 永久 |
| 设备 | 这张卡最多绑几台机器 |
| 换绑 | 允许自助换绑几次 |
| 数量 | 这条规格的总配额 |

「+ 再加一行」可以加规格，点行尾 `×` 删除该行。保存后**整体覆盖**原有配额，
但**已用数量保留**——比如原配额 20 张用了 5 张，改成 30 张后剩余变 25 张。

想临时加量：把数量改大即可（不能改到小于已用数）。

## 代理商看到什么

打开 `/agent` 只有两块：

**制卡** —— 规格下拉（只列出你分配的配额，带「剩 N 张」）、数量、前缀、备注。
生成后直接给出卡密列表，可复制或下载 TXT。

**我的卡密** —— 只能看到自己制的卡，可按状态 / 关键字筛选，能做的操作只有五个：

- 封禁
- 解封
- 解绑设备
- 重置换绑次数
- 重置为未使用

页面上明确标着「代理商无删除权限」。

## 你这边能看到什么

因为是同一个库，**不需要任何同步动作**：

| 位置 | 能看到 |
|---|---|
| 卡密库 | 每张卡带「所属代理」；筛选条件里加了 `agent` 维度（`agent=0` 是管理员自己制的） |
| 代理商页 | 每个账号的已制卡数、配额已用/总数、可用应用数、最近登录时间与 IP |
| 操作审计 | 代理商所有动作，actor 显示为 `agent:账号`，可搜 `agent.` 前缀 |

审计里能看到的具体动作：

```
agent.login / agent.login_failed
agent.card.generate    生成 N 张（应用 卡型 时长）
agent.card.ban         成功 N / 跳过 M
agent.card.unban
agent.card.unbind
agent.card.unbind_reset
agent.card.reset
```

## 权限边界（重要）

**代理商永远拿不到的操作**

| 动作 | 原因 |
|---|---|
| `delete` 删卡密 | 明确禁止，代码里白名单不含它 |
| `renew` 续期 | 能把自己的卡无限续期，等于绕过配额 |
| `ban_devices` | 收在 `ban` 里，不给独立入口 |
| 删应用 / 改套餐 / 改设置 / 重置令牌 / 备份 | 这些接口在 `/api/admin/*`，代理商令牌进不去 |

**代理商的令牌和你的管理令牌是两套东西**：`X-Agent-Token` vs `X-Admin-Token`，
路由前缀也不同（`/api/agent/*` vs `/api/admin/*`）。代理商令牌打管理接口一律 401。

**只能碰自己的卡**：操作时逐张校验 `agent_id`，不是自己制的静默跳过（返回 `skipped` 计数），
不会报错也不会泄露别人卡的存在。

**停用/改密立即生效**：`status=disabled`、重置密码、`kick` 都会清空 token，
他下一次请求就是 401。令牌本身有效期 7 天。

想放开某个动作（比如允许续期），改 `kauth/agent.py` 里的 `AGENT_ACTIONS` 元组即可，
同时要想清楚配额会不会被绕过。

## 常见问题

**配额扣了但卡没生成出来？**

落库失败时会把配额退回去（`agent.py` 的 `except` 分支）。真出现不一致，
在「配额」弹窗里把数量改大补回来即可——`quota_used` 是记账字段，不会自动回滚已删的卡。

**代理商能把卡密拿去别处卖吗？**

能，这是分销的固有风险。控制手段：给每个代理商单独的账号 + 备注前缀（制卡时填），
出问题在卡密库按 `batch` 或 `agent` 筛出来批量封禁。

**能限制他一天最多制多少张吗？**

现在只有总量配额，没有时间窗口。需要的话在 `agent.gen_cards()` 开头按 `created_at` 统计当天
已制数量即可（`cards` 表有 `agent_id` 和 `created_at`）。

**删了代理商会怎样？**

账号、配额、应用授权一起删。他制的卡**保留在卡密库**，只是「所属代理」清空，
归属变回管理员。有卡时会先要求二次确认。

**代理商能看到卡密的绑定机器码吗？**

列表里只给设备数和剩余换绑次数，不给机器码明细。要看他能自己决定给客户换绑。
需要机器码明细的场景，让他在群里报卡密、你在后台查。
